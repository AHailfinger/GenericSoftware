# EnergieAutomation.Mcp Project Summary

## Overview
`EnergieAutomation.Mcp` is a Model Context Protocol (MCP) server designed to provide the EnergyAutomate ecosystem with structured access to its internal data, tools, and documentation.

## Key Components
- **MCP Server**: Implements the MCP protocol to allow LLMs and other agents to interact with EnergyAutomate's capabilities.
- **Tools**: Provides specific tools for querying device data, executing energy calculations, and managing templates.
- **Program.cs**: Entry point for the MCP server.

## Technologies
- .NET 8+
- MCP (Model Context Protocol)
